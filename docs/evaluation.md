# 評価結果と入力R応答

[README に戻る](../README.md)

対象は `v0.1.1`（EMA）です。すべての評価は **temperature 1・全合法手を分母とした正規化・局面等重み** で行い、対局単位で学習データと分離した validation 集合を使用しています（test 集合は未使用）。なお、これらの数値はモデルの一致率や入力感度を示すものであり、指定 R での対局棋力やレーティング校正を保証するものではありません。

## 全体成績（自然頻度 50,000 局面）

| 評価集合 | 局面数 | 正解率 | policy NLL | entropy |
|---|---:|---:|---:|---:|
| 自然頻度 validation | 50,000 | 59.402% | 1.234287 | 1.220173 |

- **正解率**: 最上位の合法手と人間の指し手が一致する割合
- **policy NLL**: 実際の着手に与えた確率の負の自然対数平均（小さいほど良い）
- **第一候補変更率 / JS divergence**: 条件変更時に最上位手が変わる割合と分布間距離（本ページでは自然対数）

## 棋力帯別・手数帯別の性能

![棋力帯別の予測性能](assets/rating-performance.png)

![手数帯別の予測性能](assets/phase-performance.png)

- **棋力帯別（上図）**: 0〜2999 を 200 刻みにし、各帯 2,000 局面（計 30,000 局面）で 20 手刻みの手数帯構成比を揃えた validation 標本です。観測された自他 R・時計・最大 8 局面の履歴を入力し、陰影は対局単位 bootstrap（2,000 回）の 95% 区間を示します。
- **手数帯別（下図）**: 冒頭の自然頻度 50,000 局面を 1〜20 手・21〜60 手・61 手以降で集計したものです（戦型等による序中終盤の分類ではありません）。2つの評価集合は分布が異なるため平均値を直接比較しません。

## 入力条件と履歴の寄与

自然頻度 50,000 局面から固定 seed で抽出した 5,000 局面（基準：正解率 59.76%、NLL 1.215471）を用い、同一局面で各入力を省略した変化を測定しました。

![入力省略による変化](assets/input-effects.png)

| 省略した情報 | NLL の変化 | 第一候補変更率 |
|---|---:|---:|
| R | +0.024450 | 6.24% |
| 時計 | +0.000618 | 1.26% |
| R と時計 | +0.024933 | 6.28% |
| 過去の局面（現在局面のみ） | +0.050432 | 13.40% |

R と過去履歴の省略は NLL を悪化させました。時計省略の差は小さく、この標本からは時計の寄与を確定できません。

### 自分と相手の R を個別に変更した場合

上記 5,000 局面のうち R が既知の 2,000 局面で、片方の R だけを `500` から `2500` へ変更しました。

| 変更対象（500 → 2500） | 局面数 | 第一候補変更率 | JS divergence |
|---|---:|---:|---:|
| 自分の R | 2,000 | 25.10% | 0.0509 |
| 相手の R | 2,000 | 11.60% | 0.0150 |

自分と相手の双方の R に応じて予測分布が変化します。

## 集計データと再生成

- 集計 JSON: [全体・入力省略 JSON](metrics/v0.1.1.json) / [実R×入力R マトリクス JSON](metrics/v0.1.1-rating-matrix.json)
- R 帯別集計では 3000 以上および不明 R を除外しています。bootstrap 区間は対局単位の再抽出（2,000 回）であり、同一プレイヤーの相関や多重比較は補正していません。
- 手元の評価用 NPZ を用意すれば、以下のコマンドで再集計・再描画できます。

```console
uv sync --group analysis
uv run python tools/evaluate.py --model models/v0.1.1 --dataset /path/to/validation.npz --output docs/metrics/v0.1.1.json
uv run python tools/evaluate_rating_matrix.py --model models/v0.1.1 --dataset /path/to/matched-validation.npz --selection-info /path/to/matched-validation.json --per-band 2000 --cache work_dir/matched-metrics.npz --output docs/metrics/v0.1.1-rating-matrix.json
uv run python tools/plot_metrics.py docs/metrics/v0.1.1.json --rating-matrix docs/metrics/v0.1.1-rating-matrix.json
```
