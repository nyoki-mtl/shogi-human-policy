## `v0.1.1` の概要

作者の前作 [nyoki-mtl/maia2-shogi](https://github.com/nyoki-mtl/maia2-shogi) に続き、事前学習済みの Transformer 重みを出発点として R・持ち時間・履歴で人間の着手を条件付けしたモデルです。

| 項目 | 内容 |
|---|---|
| モデルバージョン | `v0.1.1`（EMA 重み） |
| 推論重み | float32、14,723,681 パラメータ（58,922,020 bytes） |
| 構造 | 95 token Transformer + AdaLN（Lc0 / BT4 系設計） |
| 初期重み | 事前学習済みの将棋 Transformer EMA 重み |
| 学習対象データ | 将棋倶楽部24の棋譜データ（約19億局面規模・自然頻度） |
| 学習対象の head | 人間の着手を教師とする policy のみ |
| 重みの選択 | 学習完了までの固定validation NLL最良EMA |

## 学習設定と設計方針

- **データ分離とサンプリング**: 評価用対局と同一着手列の重複を除外した上で、棋力帯・持ち時間・手数帯による均等化や oversampling は行わず自然頻度で学習しています。R や時計が不明な対局も、利用可能な policy 教師を残し条件を mask して学習に含めています。
- **条件 dropout**: 両方使用 70% / R のみ 10% / 時計のみ 10% / 両方省略 10%。
- **履歴短縮**: 8 局面 50% / 現在局面のみ 25% / 2〜7 局面を各 1/24。
- **対象外**: 個人の棋風識別や、指定 R に合わせた対局棋力の校正は行っていません。

## 数値検証範囲

- **JAX 参照出力との一致**: CPU float32 の実モデルと学習元 JAX 実装を 48 通りの局面・条件（R/時計の有無、先後、成り、駒打ち、履歴短縮）で比較し、logit の最大絶対差は `3.62396240234375e-05` でした（学習時 TPU BF16 との丸め差は生じます）。
- **CPU / CUDA float32 間の整合**: R 帯評価で使用した CUDA float32（TF32 無効）と CPU float32 を 128 局面で比較し、着手確率の最大絶対差は `1.45e-6` 未満、第一候補は全件一致しました。
- **未検証**: ONNX エクスポート、指定レーティングでの実際の対局棋力・勝率。
